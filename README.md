# Ортақ қала

Қазақ тіліндегі әлеуметтанулық зерттеу ойыны. Қазіргі жинақ — **автобус пен саябақ эпизодтарының жұмыс прототипі (0.3)**, толық төрт эпизодтық өнім емес. Барлық журнал `study_phase=dev` деп белгіленеді; негізгі зерттеу режимін қосатын параметр жоқ.

## Іске қосу

Node.js 24 немесе жаңарақ нұсқа қажет (сервер кіріктірілген SQLite қолданады).

Дайын ZIP-ті жүктеген болсаңыз, ішіндегі `ortaq-qala` папкасында **`npm start`** жеткілікті: `dist` жинағы қоса берілген. Ал бастапқы кодтан жинау үшін:

```bash
npm ci
npm run build
npm start
```

Сервер жергілікті 8787 портында жұмыс істейді. `npm run dev` сервер мен Vite әзірлеу ортасын бірге іске қосады. Қолданбаның өзі сыртқы CDN, шрифт не аналитика сервисіне сұрау жібермейді. Бұлттық ортада қарау платформаның Desktop/preview мүмкіндігі арқылы ұйымдастырылады. Жариялау мен хостинг әлі орындалған жоқ.

## Не іске асырылған

- Саябақ сызбасындағы нысандарды басып өзгерту және 8 секундтық қозғалыс көрінісінде сынау; тегін қайту/өзгерту, сынақ сызбаларының журналы.

- Келісімге дейін зерттеу сессиясы ашылмайды; бас тартуға болады.
- Серікбол, Айгүл, Мәриям, Сәдуақас: төрт бейін және әртүрлі ресурс шығыны.
- Әкімдік жауабының екі нұсқасын серверде кездейсоқ, бір рет тағайындау.
- Ақпарат ашу, ұсыныс жобасын сақтау, нақты жіберу, қатыспай аяқтау, міндетті емес clarity_bus жауабы.
- Саябақтың 6 бірліктік жоспар редакторы: картадағы өзгеріс, 16 жарамды комбинация, сақтау/қайту.
- Жоспарды топқа жариялау және онлайн/жаяу/ақылы сапар арқылы ресми таныстыру; нұсқалар бөлек сақталады.
- Серверде тексерілген әрекеттер, транзакциялық ресурс/оқиға сақтау, қайталанған сұрауға төзімділік.
- Жаңартқаннан кейін жалғастыру, жеке сессияның JSON/оқиғалар CSV/сессия CSV экспорты, деректі жою.
- Компьютер және телефонға бейімделген интерфейс, пернетақтадан қолжетімді HTML басқару элементтері.

## Алдыңғы нұсқадан жаңарту

Ескі қара терезеде Ctrl+C басып, серверді тоқтатыңыз. Жаңа ZIP-ті **бөлек папкаға** шығарыңыз. Сол папкада `npm start` орындап, браузерде `http://localhost:8787` ашыңыз. Үстінде «Сынақ нұсқасы · 0.3.0» көрінуі тиіс. Ескі папка/деректер өшірілмейді; жаңа папкада жаңа dev сессиясы басталады. Автобустан қайта өтіп, саябаққа жалғастырыңыз.

## Тексеру

```bash
npm test
npm run build
npm run test:browser
```

Браузер тестіне Chromium қажет; әдепкі жол `/usr/bin/chromium`, баламасы `CHROMIUM_PATH`. Бұлттық sandbox порт ашуға тыйым салса, платформаның рұқсат етілген орындау тетігін пайдалану қажет. Тесттер бөлек `test-results/browser.sqlite` жасайды; скриншоттар сонда сақталады. `node tests/engine.test.mjs` әр сценарийдің жеке нәтижесін көрсетеді.

## Дерек және шектеулер

Әдепкі дерекқор: `data/development-v02.sqlite`; жолды `GAME_DB`, портты `PORT` арқылы таңдауға болады. Бұл файлдар Git-ке қосылмайды. Әр браузердегі кездейсоқ кіру кілті тек сол сессияның дерегін ашады; кілт экспортқа кірмейді. Барлық қатысушыны ашатын қорғалмаған API жоқ. SQLite сервердегі файлдарды басқара алатын оператордан деректі жасырмайды.

Кездейсоқ код — нақты бірегей адамның дәлелі емес. Қайта бастау жаңа код жасайды. 30/80 қатысушы талаптары орындалды деп есептелмейді. Толық ойын аяқталуы бұл жинақта әрқашан `false`; төрт эпизодты аяқтау оқиғасы жазылмайды. Браузердің көрінуіне қарай белсенді шешім уақыты есептеледі, бірақ ол адамның назарын өлшемейді.

Нақты жинауға дейін: қалған екі эпизод; бекітілген зерттеу контактісі/сақтау мерзімі/орны; қауіпсіз орналастыру және оператор қолжетімділігі; сақтық көшірме/жою тәртібі; 1–2 пилот сессиясы; толық codebook сәйкестігі қажет. Автотесттер пилот есебін алмастырмайды.
