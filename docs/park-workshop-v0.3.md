# Ортақ қала 0.3 — саябақтағы құрастыру және сынау

Күні: 2026-11-10. Мәртебе: автобус пен саябақтың dev прототипі. Бұл қосымша 0.2 және 0.2.1 құжаттарына енгізілген өзгерістерді анықтайды. Қалған екі эпизод әзірге ойнатылмайды.

## Дизайн шешімі

Зерттеу негізі сақталады: қала тұрғыны ресурстары шектеулі жағдайда ортақ мәселеге қатысу жолын таңдайды. Ойын тәжірибесі «құрастыру → сынау → өзгерту → сақтау → ұсыну немесе өзінде қалдыру» циклімен толықтырылды. Бұл — команданың жобалық бейімдеуі; әдебиетте осы шағын модельдің әсері дәлелденді деген тұжырым жасалмайды.

Саябақ редакторында өткел, жарық және велотіреу сызба үстіндегі басылатын белгілермен қосылады/алынады. Жиек түрі сызба астынан таңдалады. Нысандардың орындары белгіленген: еркін координата таңдау немесе сүйреп апару енгізілмеген. Тінтуір, сенсорлық экран және пернетақта бірдей әрекеттерді орындайды. Дәлдік не жылдам басу бағаланбайды.

Жарамды сызбаны сақтамай тұрып 8 секундтық сынақ көрінісін ашуға болады. Көріністе тұрғын, көлік және велосипедші қозғалады. Оны тоқтатуға, жалғастыруға, қайта қосуға немесе бірден редакторға қайтуға болады. Күту міндетті емес. Қозғалысты азайту жүйелік параметрі қосылса, соңғы көрініс бірден көрсетіледі; мәтіндік түсіндірмелер де қолжетімді.

Сынау, қайту және өзгерту уақыт пен қаражат жұмсамайды. Алғаш сақтау, материалдарды ашу және жариялау құны өзгермеді. Сынау жоспарды автоматты сақтамайды, жарияламайды және азаматтық қатысу нәтижесі болып саналмайды. Сынаусыз сақтап шығу және жоспарсыз эпизодты аяқтау мүмкіндігі сақталған.

## Көріністің ашық ережелері

Модель нұсқасы: park-walkthrough-1. Бұл детерминистік иллюстрация; көлік ағыны, қауіпсіздік, қолдау немесе нақты қала нәтижелерінің болжамы емес. Кездейсоқ сәттілік, бедел ұпайы және «ең дұрыс жоспар» рейтингі жоқ.

| Компонент | Көрінетін салдар | Шектеу |
| :--- | :--- | :--- |
| Жасыл жиек | Жиек көгалданады; көлік әрі қарай өтеді | Осы жиекте тұрақ көрсетілмейді |
| Қысқа тұрақ | Көлік тұраққа кіреді | Жиектегі қосымша көгалға орын қалмайды |
| Аралас жиек | Көгал мен тұрақ қатар көрінеді | Әрқайсысына аз орын бөлінеді |
| Жаяу өткел бар/жоқ | Тұрғын жаңа өткелмен тура өтеді немесе сол жақтағы бар өткелге айналып келеді | Жолдардың ұзындығы — сызбалық, нақты метр/минут емес |
| Велотіреу бар/жоқ | Велосипедші тоқтайды немесе әрі қарай жүреді | Бір ғана шартты кейіпкердің көрінісі |
| Жарық бар/жоқ | Кешкі жолда жарық дақтары көрсетіледі немесе жол қараңғылау қалады | Қауіпсіздік деңгейіне сандық баға берілмейді |

Барлық 16 жарамды комбинация осы ережелермен көрсетіледі. Негізгі ағаштар сақталады. Ойыншы көрген сызба әлі салынған нысан емес.

## Әдіснамалық салдары

Құрастыру мен қайта қарау әрекеттері зерттеу құралының өзара әрекеттесу бөлігін күшейтеді. Сынақ көрінісі қосымша ақпарат береді және кейінгі жоспарға ықпал етуі мүмкін. Сондықтан 0.2.1 мен 0.3 саябақ деректерін бірдей құралмен жиналғандай біріктіруге болмайды; нұсқаны талдауда бөлек көрсету қажет.

Автобус жауабының екі шарты, оның бастапқы нәтижесі және clarity_bus өзгермейді. Саябақтың жаңа моделі екі шартқа да бірдей. Сынақ санын «белсенді азамат» көрсеткіші ретінде автоматты түсіндірмейміз: ол қызығу, түсінуге талпыныс немесе техникалық қайта қарау болуы мүмкін.

Жоспардың қай нұсқасы сыналды, кейін қандай өзгеріс жасалды және не сақталды деген тізбекті талдауға болады. Көріністі ашу оны толық көрді немесе түсінді деген дәлел емес. Анимация аяқталуы, тоқтатылуы және жергілікті жалғастырылуы бөлек зерттеу нәтижесі ретінде тіркелмейді. Бетті жаңартқанда көрініс басынан көрсетілуі мүмкін; жаңа сынақ оқиғасы жазылмайды, decision_presented қайта жазылады. Әрекетке дейінгі белсенді уақытқа көріністі көру де кіреді.

## Codebook қосымшасы

Метадерек: schema_version = 0.5-park.1; script_version = compact_0.2; game_version = bus-park-prototype-0.3.0; study_phase = dev. Негізгі экспорт бағандары сақталды. Бұрынғы оқиғаларға жаңа атау мен рұқсат етілген мәндер қосылды.

| Өріс | Түрі / мәндері | Мағынасы / мысалы |
| :--- | :--- | :--- |
| event_type | string: plan_trial_started | Жарамды сызбамен сынақ ашу/қайта қосу пәрмені серверде орындалды |
| payload.trial_id | UUID string | Әр жаңа іске қосуға кездейсоқ код; қайталанған request_id жаңа оқиға жасамайды |
| payload.trial_seq | integer ≥ 1 | Осы саябақтағы сынақтардың реттік саны: 1, 2, 3 |
| payload.plan_id | UUID string | Жеке жоспардың тұрақты коды |
| payload.edit_seq | integer ≥ 0 | Сыналып жатқан түзету нұсқасы; plan_revision-нан бөлек |
| payload.components | array of component strings | Сызбаның көшірмесі: edge_green, crossing, bike_rack; 0.2 компоненттер сөздігі қолданылады |
| payload.budget_used | integer 3…6 | Сыналған сызбаның құны; жалпы шек 6 |
| payload.model_version | string: park-walkthrough-1 | Көрініс ережелерінің нұсқасы |
| payload.action_id | string: park_trial_start / park_trial_replay | Редактордан сынау немесе сынақ экранынан қайта қосу |
| payload.decision_instance_id | UUID string | Пәрмен жасалған шешім экранының көрсетілуі |

Жалпы action_selected оқиғасына park_trial_start, park_trial_replay, park_trial_back әрекеттері қосылды. decision_presented/action_selected ішіндегі payload.decision_id үшін park_trial мәні қосылды; offered_actions, available_actions және blocked_reasons осы әрекеттерді қамти алады. Жарамсыз/бос сызбада park_trial_start себебі prerequisite болады. park_trial_back редакторға тегін қайтарады.

plan_component_changed бұрынғыдай әр нақты өзгерісті тіркейді. Сыналған components массиві кейінгі өзгерістен өзгермейді. plan_saved және жарияланған жоспар көшірмелерінің ережелері сақталады. Оқиғалар JSON/CSV экспортында қолжетімді; сессия қорытындысына сынақтарды азаматтық қатысу ұпайына айналдыратын баған қосылмаған.

## Тексеру және келесі пилот

Серверлік тексерістер: 33 тест, оның ішінде 16 жарамды сызба, сынақтың тегін болуы, сақтаудан бөлек тіркелуі, көшірменің өзгермейтіндігі және қайталама сұраудың қорғанысы. TypeScript пен Vite жинағы тексеріледі.

Браузер тексерісі: 1440/390 өлшемдерінде толық автобус–саябақ жолы; сызбадағы басқару; пернетақта; қозғалыстың нақты орын ауыстыруы; тоқтату/жалғастыру; қайта қосу; қозғалысты азайту; жаңартудан кейін жалғастыру; сынақтан кейін ресурс өзгермеуі; экспорт пен жою. 360 өлшемінде қатыспай аяқтау тексеріледі. Автотесттер адамның қызығуын дәлелдемейді.

Келесі адам қатысатын шағын сынақта: сызбадағы белгілерді түсіну, өзгерістің салдарын байқау, сынақтан редакторға өздігінен қайту, қайталанудың қызықтылығы және эпизодтың ұзақтығы бақыланады. Бұл пилот әлі өткізілген жоқ. Кейіпкердің еркін жүруі, тірі чат және қалған екі эпизод осы жинаққа кірмейді.

## Іске қосу

Ескі серверді Ctrl+C арқылы тоқтатыңыз. 0.3 ZIP-ті бөлек папкаға шығарыңыз. ortaq-qala папкасында cmd ашып, npm start орындаңыз. http://localhost:8787 бетін Ctrl+F5 арқылы жаңартыңыз. Үстінде «Сынақ нұсқасы · 0.3.0» болуы тиіс. Node.js 24+ қажет; дайын ZIP үшін npm ci қажет емес. Ескі папка мен журналдарды сақтаңыз.

Саябаққа жеткенде редакторды ашыңыз → жиек пен нысандарды таңдаңыз → «Жоспарды байқап көру» басыңыз → сызбаға қайтып бір нысанды өзгертіңіз → қайта байқап көріңіз → қалауыңызша сақтаңыз. Сынау міндетті емес.
