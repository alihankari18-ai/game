# Автобус прототипін техникалық тексеру

Күні: 2026-11-09. Жинақ: bus-prototype-0.1.0. Бұл автоматты техникалық хаттама; адамдармен өткізілген пилот есебі емес.

## Тексеру құрамы

- TypeScript тексеруі және Vite production жинағы.
- 13 серверлік сценарий: келісімсіз сессия жоқ; келісім сұрауын қайталау; 4 кейіпкер × 2 шарттағы ресурс/жоба/аяқтау; белгісіз және нөл primary айырмасы; қате реттілік пен ескі терезе; токенге сай қолжетімділік пен жою.
- Chromium: 1440×1000 desktop және 390×844 mobile. Келісім, кейіпкер, негізгі эпизод, reload, экспорт, жою.
- Сервер сақтап қойған ұсыныстың жауабын желіде әдейі жоғалту; reload/retry кейін бір completion және бір шығын ғана қалуын тексеру.
- CSV файлдарын жүктеу; браузердегі JavaScript қатесі мен көлденең overflow болмауын тексеру.
- Скриншоттарды көзбен қарау; телефонда карта/тақырыптың қабаттасуын түзету.

## Нәтиже және шегі

Автоматтандырылған сценарийлер өтті. Браузер сынақтары осы Chromium ортасына қатысты; басқа браузерлердегі және нақты арзан телефондардағы өнімділік әлі өлшенген жоқ. Шарттарды тең үлестіру статистикалық кепіл емес: 1:1 ықтималдықпен кездейсоқ тағайындалады.

Тесттер dev дерекқорын қолданады және негізгі таңдамаға кірмейді. Шынайы бірегей қатысушы саны: осы жұмыс аясында жиналған жоқ. Төрт эпизодқа арналған 12–15 минуттық мақсат расталған жоқ. Интерфейстегі әдебиетке сүйенген толық белсенділік профилі бірінші эпизодтан шығарылмайды.
