Төрт эпизод: автобус, саябақ, аула жарығы, кітапхана/жастар орталығы. Негізгі эксперимент — автобус жауабының нақтылығы; қалғандары сипаттамалық жалғастық.

Бұрынғы жеке автобус/саябақ файлдары кеңейтілген архивтік жобалар. Олардың 15–20 минуттық болжамы, энергия жолағы, қадам сайын ресурс алу және ескі профиль максимумдары ағымдағы қысқа нұсқаға қолданылмайды. Олар салыстыру үшін сақталды.

Әдебиеттерді пайдаланушы қолмен растаған. Картадағы механика байланыстары — жобалық бейімдеу; нақтыланбаған дәйексөз/бет ойдан қосылмаған. Автобус пен саябақ эпизодтарының 0.2 dev прототипі құрастырылды. Нақты пилот, негізгі қатысушы деректері және жарияланған ойын әзірге жоқ.
