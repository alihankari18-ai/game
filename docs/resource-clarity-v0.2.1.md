# Ортақ қала 0.2.1 — ресурс пен жоспар жасау жолы

Күні: 2026-11-10. Бұл автобус пен саябақтың dev прототипіне арналған түзету. Қалған екі эпизод әлі ойнатылмайды.

## Не түзетілді

Жоспар редакторын ашу, жоспарды сақтау және оны ұсыну жеке қадамдар ретінде көрсетіледі. Редактор тегін ашылады. Алғаш сақтаудың құны мен одан кейін қалатын уақыт алдын ала көрінеді. Топқа жариялау және ресми таныстыру үшін сақталған жоспар қажет екені жабық батырмаларда жазылады. Қор жетпегенде нақты қажет және бар мөлшер көрсетіледі; түсіндірме мәтіні жабық батырмада да оқылады.

Жоспар сақталмаған жағдайда эпизодтан шығу алдында бейтарап растау экраны ашылады: таңдауларға қайтуға немесе жоспарсыз аяқтауға болады. Қатыспау үшін айып қосылмайды.

## Үш бөлек қор

| Қор | Мағынасы | Қалай жұмсалады |
| :--- | :--- | :--- |
| Уақыт бірлігі | Кейіпкердің осы эпизодтағы істеріне бөлінген шартты мүмкіндік | Құны көрсетілген әрекетпен; нақты минут өткеннен азаймайды, күткеннен толмайды |
| Жоба бюджеті | Саябақ жоспарына берілген 6 бірлік | Жиек пен қосымша нысандарды таңдау арқылы; жеке уақыт емес |
| Жеке қаражат | Кейіпкердің жол шығынына арналған қоры | Ресми таныстыруға ақылы сапар таңдағанда ғана |

Саябақ басталғанда уақыт пен қаражат бейінге сай қайта беріледі. Автобустағы шығын саябаққа көшірілмейді. Материалдарды алғаш ашу бұрынғыдай бейінге сай уақыт жұмсайды, қайта ашу тегін. Оқу ұзақтығы есептегі қорды азайтпайды.

Мәриям мысалы: саябақта 3 уақыт → материалдарды алғаш ашқаннан кейін 2 → алғашқы жоспар сақталғаннан кейін 1. Жоба бюджетінің барлық 6 бірлігін қолдану жоспарды сақтауға кедергі болмайды. Әрекеттердің құны, бастапқы қорлар және автобус эксперименті өзгерген жоқ.

## Диагностиканың шегі

Тексерілген dev өтуінде жоспар редакторын ашу және жоспар сақтау оқиғалары тіркелмеген; қалған уақыт алғашқы сақтауға жеткілікті болған. Топқа жариялау мен ресми таныстыруға жоспардың болмауы кедергі болған. Бұл журнал адамның нақты нені басқысы келгенін немесе түсінбеушіліктің субъективті себебін анықтамайды. Жабық батырманы басу талпыныстары бөлек тіркелмейді. Бұл техникалық диагностика, ресми пилот нәтижесі емес. Шикі жеке журнал осы жинаққа енгізілмейді.

## Codebook қосымшасы

Алдыңғы бағандар мен оқиға түрлері сақталды. 0.2 құжатындағы рұқсат етілген мәндер төмендегі мәндермен толықтырылады.

| Айнымалы | Түрі | Жаңа мән | Мағынасы / мысалы |
| :--- | :--- | :--- | :--- |
| schema_version | string | 0.4-park.2 | Жаңа навигация мәндерін қамтитын журнал схемасы |
| game_version | string | bus-park-prototype-0.2.1 | Осы интерфейс жинағы |
| payload.decision_id | string | park_exit | decision_presented және action_selected оқиғаларында: сақталған жоспарсыз аяқтауды растау экраны; API күйіндегі phase мәні де park_exit |
| payload.action_id; payload.offered_actions / available_actions элементтері | string | park_exit_open | Растау экранын ашу; уақыт жұмсамайды, эпизодты аяқтамайды |
| payload.action_id; payload.offered_actions / available_actions элементтері | string | park_exit_back | Таңдауларға қайту; уақыт жұмсамайды |

`park_end_confirm` сақталған жоспары бар хабта немесе `park_exit` экранында қолжетімді. Расталғанда бұрынғыдай `scenario_completed` жазылады. Жаңа экранды ашу/кері қайту жалпы әрекет журналдары мен шешім экрандары арқылы тіркеледі; жаңа зерттеу нәтижесі енгізілген жоқ. `study_phase=dev`, `script_version=compact_0.1`, толық ойын аяқталуы `false` болып қалады.

0.2 мен 0.2.1-де әрекеттердің көрінуі мен шығу жолы өзгеше: оларды талдауда нұсқаларды ажырату қажет. Экспорт метадерегі ағымдағы сервер нұсқасын көрсетеді, жеке оқиғалар өз нұсқасын сақтайды. Ескі дерекқорды жаңа кодпен жалғастырса, оқиғалардың нұсқалары араласуы мүмкін. Ұсынылатын жаңарту — жаңа папкада жаңа dev өтуі; ескі папка мен журналдар сақталады.

## Тексеру

31 серверлік тест өтті: барлық кейіпкерлер мен екі шарт, ресурс есептері, 16 жарамды жоспар, жарияланған нұсқалардың сақталуы, қайталама сұраулар, жаңа шығу/қайту жолы және Мәриямның материалдарды екі рет ашып, толық бюджетті жоспар сақтау жолы тексерілді. TypeScript және өндірістік жинақ сәтті өтті.

Chromium: 1440 және 390 пиксельде автобус пен саябақтың толық жолдары, ресурс түсіндірмелері, жоспарсыз шығудан бас тарту, 0 бюджет қалдығымен сақтау, экспорт/жою тексерілді. 360 пиксельде екі эпизодты қатыспай аяқтау тексерілді. JavaScript қатесі және көлденең тасу анықталмады. Бұл автотесттер адам қатысатын пилотты алмастырмайды.

## Windows-та жаңарту

1. Бұрынғы қара терезеде Ctrl+C басыңыз. Терезе жабық болса, бұл қадам қажет емес.
2. 0.2.1 ZIP-ті бөлек папкаға толық шығарыңыз. Ескі папка мен журналды сақтаңыз.
3. Жаңа жинақтағы ortaq-qala папкасын ашыңыз. Жол жолағына cmd жазып, Enter басыңыз.
4. Қара терезеде npm start орындаңыз. Node.js бұрын орнатылған болса, қайта орнату және npm ci қажет емес.
5. Браузерде http://localhost:8787 ашып, Ctrl+F5 басыңыз. Жоғарыда «Сынақ нұсқасы · 0.2.1» болуы тиіс.
6. Жаңа сынақ өтуін бастаңыз. Саябақта «Жоспар редакторын ашу» арқылы сызбаны құрастырып, сақтауға болады.
